# Happy Heals 🩹

The coolest bandages on Earth — designer adhesive bandages for kids in fun shapes and characters.

## About

Happy Heals makes bandages that turn every "ouch" into an "ooh, COOL!" From mighty T-Rex to friendly astronauts, our designs help boo-boos heal with a smile.

## Pages

- `index.html` — homepage with hero, product collection, story, and reviews
- `dino-bandages.html` — Dino Bandages product detail page
